# handy-scripts
A personal drawer of handy scripts, browser tweaks, automation snippets, and small coding tricks.

## Chaoxing auto video

文件：

`browser/chaoxing-auto-video.js`

用途：

超星课程中，如果每小节是「视频 + 测验」，可以先连续播放所有视频，暂时跳过测验。

使用：

1. 打开课程页面
2. 按 `F12`
3. 打开 Console
4. 左上角执行环境选择 `top`
5. 粘贴运行脚本

效果：

视频播放完 → 跳过本节测验 → 进入下一节视频 → 自动播放。
